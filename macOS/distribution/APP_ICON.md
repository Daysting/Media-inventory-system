The icon uses the DaystingIRC family’s cyan, cobalt, and violet glass tile, with a frosted open book and blue plus symbol. The publisher approved this design on September 25, 2026. It ships in version 1.6, build 161.

The 1024-pixel source is `macOS/MediaInventory/MediaInventory/Assets.xcassets/AppIcon.appiconset/icon_512x512@2x.png`. Run `./script/generate_app_icon.sh` to derive every smaller macOS asset while preserving transparency. The older `AppIcon_open_book_plus.svg` is a historical design and is not used by the app.

Created with the built-in image generation tool, using the installed DaystingIRC icon as a style reference and the previous Inventory icon as a subject reference.
